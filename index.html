URL Scraper

A lightweight async scraper for extracting company_name, website, and linkedin_url from public pages, directories, forums, and social threads.

Async fetch Concurrent HTTP scraping with retries and timeout handling.
Layered extraction Metadata, link analysis, text heuristics, and domain inference.
Strict output Returns null instead of guessing when confidence is low.
